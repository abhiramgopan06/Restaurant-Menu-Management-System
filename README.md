# Restaurant Menu Management System

A beginner-friendly Django practical project using Django, SQLite, HTML, and CSS.

## Features
- Add, view, edit, and delete food items
- Ask for confirmation before deleting a food item
- Filter menu items by category using the Django ORM
- Change availability directly from the menu listing
- Validate required fields and ensure the price is greater than zero
- Optional food images with image-file validation
- Success and validation messages
